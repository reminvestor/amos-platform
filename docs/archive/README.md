# Documentation Archive

This folder contains historical documentation from the development process.

## Folder Structure

- **`fixes/`** - Old bug fix notes and temporary workarounds
- **`development/`** - Phase-based development notes, agent lightning docs
- **`migrations/`** - AWS and infrastructure migration guides
- **`implementation_notes/`** - Completed feature implementation summaries

## Why Archived?

These documents were created during active development and contain:
- Point-in-time decisions that may no longer be relevant
- Implementation details that have since changed
- Migration guides for completed migrations
- Fix notes for resolved issues

## Current Documentation

For current platform documentation, see:
- **`/PLATFORM_CAPABILITIES.md`** - Single source of truth for what the platform can do
- **`/README.md`** - Project overview and setup instructions
- **`/CLAUDE.md`** - AI assistant context file
- **`/docs/architecture/`** - Current architecture documents

## Note

These documents are preserved for historical reference but should not be treated as current documentation. Always refer to `PLATFORM_CAPABILITIES.md` for the authoritative description of platform features.
