# Advanced Mode Sidebar Structure

## Proposed Organization:

1. **Dashboard** (always expanded)

2. **Marketing** (collapsible dropdown)
   - Campaigns
   - Landing Pages
   - Email Templates
   - Social Posts

3. **Contacts** (collapsible dropdown)
   - All Contacts
   - Groups

4. **Content** (collapsible dropdown)
   - Images

5. **Settings** (collapsible dropdown)
   - Integrations
   - Business Profile
   - Entity Settings

6. **Management** (collapsible dropdown - for entity admins)
   - Team Members
   - Observability

Top Navbar:
- "Chat Mode" toggle button (top right)
- User dropdown with profile, admin portal access

This structure groups related items and reduces visual clutter.
